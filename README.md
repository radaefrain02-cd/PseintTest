# RegistroSeguro - PSeInt

Programa en PSeInt para la materia PFU-111 (Grupo 2). Arreglamos un código de registro original que aceptaba cualquier dato sin revisar y le pusimos validaciones para que no se rompa ni acepte cosas raras.

## ¿Qué se mejoró?

* **Validación de edad:** Solo acepta edades entre 1 y 120 años
* **Validación de notas:** Solo permite notas entre 0 y 100
* **Menú controlado:** Solo te deja elegir las opciones 1, 2 o 3
* **Manejo de errores:** Si pones un dato inválido, muestra un mensaje y te lo vuelve a pedir sin cerrar el programa

## ¿Cómo probarlo?

1. Descarga el código del repositorio[cite: 7].
2. Ábrelo en PSeInt.
3. Dale a **Ejecutar** y prueba meter números negativos o muy altos para comprobar que los rechaza.
